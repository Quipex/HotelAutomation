# Sync DTO Package

This package contains Data Transfer Objects (DTOs) specifically for communication with external Property Management Systems (PMS).

## Files

- **AuthRequestDto.java** - DTO for PMS authentication requests, containing credentials needed to authenticate with the external system.

- **AuthResponseDto.java** - DTO for PMS authentication responses, containing authentication tokens and other session information returned by the external system.

- **BookingDto.java** - DTO representing booking data as received from or sent to the external PMS system, with fields and formats aligned with the external system's requirements.
